# Shared Packages

این پوشه برای منطق و قراردادهایی است که واقعاً باید بین چند برنامه یا لایه به اشتراک گذاشته شوند. هر package باید مالکیت روشن، API کوچک و تست مستقل داشته باشد.

| Package | مسئولیت |
|---|---|
| contracts | قراردادهای درخواست/پاسخ API و DTOهای مشترک |
| validation | schemaهای validation قابل استفاده در فرانت‌اند و بک‌اند |
| learning-core | قواعد خالص یادگیری، ارزیابی و پیشرفت، بدون وابستگی به Cloudflare |
| ai-adapters | interface ارائه‌دهندگان AI و تبدیل ورودی/خروجی |
| telegram-core | توابع مستقل و قابل تست برای قالب‌بندی و قراردادهای Telegram |

قواعد:
- از circular dependency جلوگیری شود.
- package مشترک نباید secret یا binding محیطی داشته باشد.
- منطق امنیتی و مجوز سمت سرور همچنان در بک‌اند enforce می‌شود؛ اشتراک validation جایگزین آن نیست.
- package جدید فقط وقتی ساخته شود که مصرف‌کنندهٔ واقعی یا مرز معماری مشخص داشته باشد.
